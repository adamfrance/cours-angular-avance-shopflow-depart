# ShopFlow : application de départ de la formation Angular avancé

Boutique en ligne en Angular 22 dans un projet Angular CLI classique (Nx sera installé au module 1). Données : API publique https://dummyjson.com (compte de démonstration : emilys / emilyspass).

```bash
npm install
npm start                 # http://localhost:4200
npm run build             # build de production
```

L'application fonctionne mais contient volontairement les défauts que la formation analyse puis corrige, module par module.
